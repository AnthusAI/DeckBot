# DeckBot Help

## Slash Commands

Slash commands provide quick access to common actions:

- **`/fast`** - Toggle fast mode to use the secondary (faster) model for all messages
- **`/fast <message>`** - Send a one-shot message using the fast model without toggling mode
- **`/export`** - Export your presentation to PDF format
- **`/help`** - Display this help information
- **`/tools`** - List all available agent tools and their descriptions

## Keyboard Shortcuts

- **`Ctrl+Enter`** or **`Cmd+Enter`** - Send your message
- **`Ctrl+K`** or **`Cmd+K`** - Focus the chat input field
- **`Ctrl+3`** or **`Cmd+3`** - Toggle code view

## UI Tips

### Chat Interface
- Type messages in the chat input to interact with the AI agent
- Upload images by dragging them into the chat
- The agent can view images and incorporate them into your presentation

### Slide Navigation
- Click on slide preview thumbnails to jump to a specific slide
- Use the slide navigator to see all slides at a glance
- Slides update automatically as you edit the presentation

### Code View
- Access the code view to directly edit presentation files
- View and modify `deck.marp.md`, styles, and other assets
- Changes are saved automatically

### Layouts
- Browse available presentation layouts
- Apply layouts to individual slides or the entire deck
- Customize layout colors and styles in settings

### Settings
- Configure presentation aspect ratio (16:9, 4:3, 1:1)
- Set image generation preferences
- Manage design opinions and style guidelines

## Getting Started

1. **Create a new presentation** or load an existing one from the welcome screen
2. **Chat with DeckBot** to describe what you want in your presentation
3. **Review and edit** the generated slides
4. **Export to PDF** when you're ready to share

For more information, visit the [DeckBot documentation](https://github.com/your-org/deckbot).
